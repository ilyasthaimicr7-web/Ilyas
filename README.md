# Horror Studio AI

A mobile-friendly web app for creating original English horror stories for YouTube.
Built for phone-only operation via Kilo Cloud Agent.

> **Version 0.2 — Stage 1: Real AI Story Generation.**
> The backend now connects to Google Gemini for real story and YouTube metadata generation.

---

## What's New in Stage 1

- **Secure Node.js backend** (Express) that serves the frontend and proxies AI requests.
- **Real Gemini integration** — stories and YouTube metadata are generated by Google's Gemini API.
- **API key security** — `GEMINI_API_KEY` is loaded from `.env` on the server only. It is never sent to the browser.
- **Video + Shorts formats** — generate long-form scripts (3/5/10 min) or Shorts scripts (30/45/60s).
- **YouTube metadata** — title, description, thumbnail concept, scene-by-scene production plan, tags.
- **Error handling** — clear messages for missing key, quota limits, invalid keys, and network errors.
- **Demo Mode** — still available for offline UI testing without an AI service.

## Setup — Get Your Gemini API Key

Stage 1 uses **Google Gemini** (free tier, no credit card required).

1. On your phone, open [Google AI Studio](https://aistudio.google.com/apikey) in Chrome.
2. Sign in with your Google account.
3. Tap **"Create API key"** → copy the key.
4. **On your phone**, store it securely. See [Storing Your API Key](#-storing-your-api-key) below.

---

## Storing Your API Key

> **Your key never enters our chat. It is stored in a gitignored `.env` file on the server.**

### Option A: Via bash (recommended)

On your phone, use the bash tool to write the key directly:

```bash
printf 'GEMINI_API_KEY=YOUR_ACTUAL_KEY_HERE\n' > .env
```

Replace `YOUR_ACTUAL_KEY_HERE` with your real Gemini API key. The key appears in your command, not in this chat.

### Option B: Using the write tool

Create a file at `/workspace/app/.env` with:

```
GEMINI_API_KEY=YOUR_ACTUAL_KEY_HERE
```

### Verify (without exposing the key)

After creating `.env`, check that it's set:

```bash
node -e "require('dotenv').config(); console.log(process.env.GEMINI_API_KEY ? 'Key is set ✓' : 'Key is NOT set ✗');"
```

## Running the Backend

1. **Install dependencies** (one-time):

   ```bash
   npm install
   ```

2. **Start the server**:

   ```bash
   npm start
   ```

   You'll see output like:
   ```
   Server: http://0.0.0.0:8123
   API Key: ✓ Configured
   Model: gemini-2.0-flash
   ```

3. **Expose to the internet** (for phone access):

   ```bash
   npx cloudflared tunnel --url http://localhost:8123
   ```

   Copy the `*.trycloudflare.com` URL.

## How to Use

1. **Enter a story idea** — e.g., "A grandmother's attic mirror shows visitors their death."
2. **Choose format** — "YouTube Video" (long-form) or "YouTube Shorts" (short script).
3. **Choose duration** — 3/5/10 min for Video, 30/45/60s for Shorts.
4. **Toggle Demo Mode off** (it's off by default once the key is configured).
5. **Tap "Generate Story"** — the AI creates an original horror story.
6. **Tap "Generate YouTube Title & Description"** — the AI creates metadata.
7. **Tap "Copy Story" or "Copy Metadata"** to paste into other apps.

## Free Tier Limits

**Google Gemini (gemini-2.0-flash):**
- **Free:** ~1,500 requests/day, no credit card required to sign up.
- **Rate limit:** ~1,000 tokens per minute.
- **Beyond free tier:** pay-per-token (very low cost).
- **Get key:** https://aistudio.google.com/apikey

## Error Messages

| Message | Meaning |
|---|---|
| "No AI service configured" | `.env` is missing or `GEMINI_API_KEY` is empty. Restart the server. |
| "AI quota exceeded" | You've hit the free rate limit. Wait ~60 seconds and try again. |
| "API key is invalid or expired" | The key in `.env` is wrong. Update it and restart. |
| "Network error" | The server can't reach Google's API. Check connectivity. |
